ESA Spectrum Quest
==================

Open index.html in a modern browser.

What is included:
- Full radio-to-gamma interactive spectrum scanner
- 12 ESA/Copernicus mission dossiers
- Verified mission wavelength/frequency descriptions
- Official ESA data examples loaded from ESA-hosted image URLs
- Links to ESA mission descriptions, original satellite-image pages, and data-image source pages
- 16-question mission challenge
- Space Cadet badge unlock at 60 points

Internet connection:
The game itself and Space Cadet badge work locally. Official ESA imagery is loaded from ESA's website, so an internet connection is required to display those images and open source links.

Licensing:
ESA imagery has asset-specific licence and credit requirements. Open each linked ESA data-image source before redistributing images. This game is an independent educational prototype and is not an official ESA product.
